The SVG exports are copied unchanged from `docs/App-Icon/Apple/<Name>/@SVG.svg`.
The app's existing CSS applies the rounded icon mask.

| Local file | Use |
| --- | --- |
| Photos.svg | Photos |
| Contacts.svg | About |
| Pages.svg | Projects |
| Notes.svg | Blog |
| Mail.svg | Contact and Email |

The upstream README states that these icons may be downloaded and used free
for personal projects. See the [README at the pinned revision](https://github.com/aroundsketch/Apple-App-Icons/blob/83454085514a0ca3b1855493308ad67056d7af4e/README.md).

Apple app names and associated marks belong to Apple. This personal portfolio
is not affiliated with Apple. Spotify and GitHub artwork use their existing
sources; Windows desktop icons are configured separately.
